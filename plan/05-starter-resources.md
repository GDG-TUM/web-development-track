# 5. Starter resources

| Resource | Use it for | Link |
|---|---|---|
| MDN Web Docs | HTTP and browser fundamentals | https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Overview |
| OWASP Top 10:2025 | Common web application risks | https://owasp.org/projects/top-ten?lang=en |
| PortSwigger Web Security Academy | Guided web security labs | https://portswigger.net/web-security |
| OWASP ZAP | Authorised web security testing | https://www.zaproxy.org/ |
| Burp Suite Community | Inspect HTTP traffic in a lab | https://portswigger.net/burp/communitydownload |
| GitHub Docs | Issues, pull requests and collaboration | https://docs.github.com/ |

> Use ZAP and Burp only against the team's own prototype or an explicitly authorised training environment.
