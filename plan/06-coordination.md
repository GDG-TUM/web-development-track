# 6. Coordination with the Web lead

## Before coding
Agree on features, user roles, data collected, technology stack and which security requirements apply.

## During development
Hold a brief weekly check-in, review new features and raise issues early through the agreed channel or GitHub issues.

## Before testing
Confirm the target environment, permission, scope and safe testing window. Use the [pre-testing checklist](../checklists/pre-testing.md).

## When a finding is reported
Include: reproduction steps, affected feature, impact, evidence, severity, recommended fix, owner and retest status. Use the [finding report template](../templates/finding-report.md).

## Before the showcase
Remove secrets and sensitive data, agree on a safe demo and disclose unresolved issues honestly. Use the [pre-showcase checklist](../checklists/pre-showcase.md).
