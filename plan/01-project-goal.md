# 1. Project goal

Build a manageable finance-portal prototype and demonstrate how security can be included **from planning through testing**.

| Track | Owns |
|---|---|
| **Web track** | Application structure and features |
| **Cybersecurity track** | Security requirements, risk assessment, coordination of authorised testing, documentation of fixes and limitations |

This plan explains how the Cybersecurity track supports a student finance web-application prototype inspired by the functions of a university finance portal. It aligns with the project brief: web basics, authentication, secure coding, vulnerability testing, GitHub documentation and a Week 13 showcase.

> **Scope boundary:** build and test the team's own prototype using fictional student records and simulated transactions. Do not test the live TUM finance system without explicit written authorisation.
