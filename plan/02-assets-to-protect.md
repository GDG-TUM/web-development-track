# 2. What the Cybersecurity track should protect

## Student financial information
Fee balances, statements, payment histories and student details must only be visible to the correct account or authorised staff.

## Payment integrity
A transaction should be marked successful only after the server verifies the result. The browser must not be trusted to set balances or payment status.

## Finance staff actions
Only authorised staff should make financial adjustments. Important changes should have an audit trail showing who acted, what changed and when.

## Account and session security
Protect logins, sessions, password-reset flows and privileged accounts where these features are in scope.
