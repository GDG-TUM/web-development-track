# 7. Definition of success

- [ ] A security plan and requirements are agreed with the Web lead before or early in development.
- [ ] Test cases are tied to the actual finance-portal features.
- [ ] Authorised findings are recorded, prioritised, fixed where feasible and retested.
- [ ] The repository includes clear security notes and no intentionally committed credentials or tokens.
- [ ] The Week 13 demo explains the risk, control or fix, and retest result.
