# 4. Learning priorities

- **Web foundations:** HTTP/HTTPS, requests and responses, cookies, sessions, browser Developer Tools and basic backend/database concepts.
- **Identity and permissions:** Authentication versus authorisation, role-based access control, session security and password storage.
- **Common vulnerabilities:** OWASP Top 10, especially broken access control, injection, security misconfiguration and authentication failures.
- **Finance-specific logic:** Server-side balance calculation, transaction verification, duplicate transaction handling and audit trails.
- **Testing and reporting:** Write test cases, use Burp Suite Community or OWASP ZAP in an authorised lab, record findings, prioritise fixes and retest.
