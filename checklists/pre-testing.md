# Before testing

- [ ] Target environment confirmed as the team's own prototype or an authorised training lab
- [ ] Permission recorded in the [authorisation record](../ETHICS-AND-RULES.md)
- [ ] Scope (features, roles) agreed with the Web lead
- [ ] Safe testing window agreed
- [ ] Only fictional data and simulated payments in the environment
- [ ] No real payment credentials configured
- [ ] Test plan prepared and test cases prioritised
- [ ] Vulnerability register and finding template ready
- [ ] The live TUM finance system is **not** a target
