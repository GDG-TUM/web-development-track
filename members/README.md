# 👥 Members

Add your profile as your first pull request. It tells the team who you are and how you want to contribute.

## How

1. Copy [`TEMPLATE.md`](TEMPLATE.md) to `members/your-github-username.md`
2. Fill it in
3. Open a pull request

> [!WARNING]
> Do not put phone numbers, passwords, registration numbers or any private data in your profile.

## Roles on this project

| Role | What you do |
|------|-------------|
| **Security reviewer** | Review new features against the requirements, raise issues early |
| **Tester** | Run authorised test cases on our own prototype, record findings |
| **Developer liaison** | Work with the Web track to fix findings and retest |
| **Documenter** | Keep the register, retest log and report up to date |
