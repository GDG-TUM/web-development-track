# 🚀 Getting started

Complete this checklist before the first check-in. Most of it is one-time setup.

## 1. Accounts

- [ ] A [GitHub](https://github.com) account
- [ ] **Two-factor authentication** turned on
- [ ] Joined the [GDG-TUM organization](https://github.com/GDG-TUM)
- [ ] Added to the project channel **[TO CONFIRM]** group link

## 2. Read first

- [ ] [Ethics and rules](ETHICS-AND-RULES.md)
- [ ] [Project goal](plan/01-project-goal.md) and [what we protect](plan/02-assets-to-protect.md)
- [ ] [Week-by-week roadmap](roadmap/week-by-week.md)

## 3. Tools

You only need these once testing starts (Week 8 onward). Install them on your own laptop.

| Tool | Use | Link |
|------|-----|------|
| Browser Developer Tools | Inspect requests, cookies and storage | Built into Chrome, Edge and Firefox |
| OWASP ZAP | Authorised web security testing | https://www.zaproxy.org/ |
| Burp Suite Community | Inspect HTTP traffic in a lab | https://portswigger.net/burp/communitydownload |
| Git | Clone, branch and push | https://git-scm.com/ |

> [!TIP]
> **Old or slow laptop?** Start with the browser-based labs on [PortSwigger Web Security Academy](https://portswigger.net/web-security) and browser Developer Tools. Those need no installation.

Follow [Learning priorities](plan/04-learning-priorities.md): web foundations, identity and permissions, OWASP Top 10, finance-specific logic, testing and reporting. Free resources are in [Starter resources](plan/05-starter-resources.md).
