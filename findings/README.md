# Findings

One file per finding, named `V-XX-short-title.md`, created from the [finding report template](../templates/finding-report.md).

- Redact tokens, cookies and any sensitive values in evidence.
- Add a matching row to the [vulnerability register](../templates/vulnerability-register.md).
- Link the GitHub issue and the fix PR.
- Record retests in the [retest log](../templates/retest-log.md).
