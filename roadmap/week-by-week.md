# Week-by-week plan

| Period | Cybersecurity actions | Deliverable |
|---|---|---|
| Week 5–6 | Meet Web lead; confirm features, roles, data, technology and deployment plan. Identify key risks. | Security brief and threat list |
| Week 7 | Agree testing boundaries; create checklist, test-plan template and vulnerability register. | Security workflow and templates |
| Weeks 8–9 | Study relevant OWASP risks; review new features; prepare test cases. | Prioritised test cases and review notes |
| Week 10 | Test own development version with permission: access control, input handling, sessions and transaction logic as applicable. | Initial findings and remediation tasks |
| Weeks 11–12 | Work with developers to fix findings; retest; complete security notes and report. | Retest log and draft report |
| Week 13 | Demonstrate prototype, safely show a finding and its fix, and explain remaining limitations. | Security demo and final report |
